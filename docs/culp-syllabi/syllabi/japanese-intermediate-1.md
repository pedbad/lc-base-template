## Michaelmas term

### Lesson 1: Grumble and Gossip 1

Textbook chapter: (第 17 課 I )

**Language Functions**

- Talking about something you heard

**Grammar Structures & Expressions**

- "Hearsay report" Seemingly, (I hear)
  - Plain Style+そうです。
  - 日本語を話すそうです。(Verbs)
  - 友達の家は大きいそうです。(i-adj)
  - 奥さんはにぎやかだそうです。(na-adj)
  - 先生は日本人だそうです。(noun)
- Quoting what you heard
  - PS + って。(Informal)
  - 日本語を話せるって。(Verbs)
  - 友達の家は大きいって。(i-adj)
  - 奥さんはにぎやかだって。(na-adj)
  - 先生は日本人だって。(noun)

**Work after Class**

- Kanji: 歳 結婚 主 集
- Week 18 Verbs
- Read 「初めてのアルバイト」

**Learning objectives**

- to revise PS structure 時(When)
- to revise MF+ そうです。
- to practice PS+そうです。
- to be able to report things you heard

### Lesson 2: Grumble and Gossip 2

Textbook chapter: (第 17 課 II)

**Language Functions**

- Conditionals

**Grammar Structures & Expressions**

- Conditional (revision)
  - た F＋ら。
  - 漢字がわかったら楽しい。(Verbs)
  - 安かったらかいたい。(i-adj)
  - ひまだったら遊びに来て。(na-adj)
  - 試験だったら忙しいね。(noun)
- Describing what you do not need to do.
  - ない F＋くてもいいです。
  - 辞書をかわなくてもいいです。(Verbs)
  - プレゼントは高くなくてもいい。(i-adj)
  - 大学は有名じゃなくてもいい。(na-adj)
  - 旅行は日本じゃなくてもいい。(noun)

**Work after Class**

- Kanji: 品 発表 活 写真
- Week 19 Verbs
- Translation [Imagine] by John Lennon

**Learning objectives**

- to be able to use different conditionals confidently
- to revise ないＦ structures
- to be able to say what you don't need to do

### Lesson 3: Grumble and Gossip 3

Textbook chapter: (第 17 課 III)

**Language Functions**

- Giving / Receiving some advice

**Grammar Structures & Expressions**

- Expressing the idea that something/one resembles using the noun.
  - Noun＋みたいです。
  - 父はサンタクロースみたいです。
  - 大学で勉強できて夢みたいです。
- Expressing the idea that something "appears to be the case"
  - PS＋みたいです。
  - 雨が降ったみたいです。(Verbs)
  - バスが来ないみたい。(Verbs)
  - プレゼントは高いみたいです。(i-adj)
  - その店は有名みたいですよ。(na-adj)
- Describing the event *before* something happens. (Revision)
  - DF＋前に/ てF+ から

**Work after Class**

- Kanji: 歩 野 字
- Week 20 Verbs
- Read 「オノ・ヨーコ」

**Learning objectives**

- to be able to describe resemblance Noun＋みたいです。
- to be able to express your feelings by using Noun＋みたいです。
- to use both DF＋前に/ て F+ から confidently

### Lesson 4: John's Part-time job 1

Textbook chapter: (第 18 課 – I )

**Language Functions**

- Reporting someone's speech

**Grammar Structures & Expressions**

- Transitive / Intransitive Verbs
  - 開ける 開く
  - 閉める 閉まる
  - つける つく
  - 消す 消える
- て F ＋しまう。（revision）
  1. To complete an action: リストの漢字をおぼえてしまいます。
  2. To do something regrettably: さいふを落としてしまいました。 大事な会議におくれてしまいました。
- Conditional –whenever something happens, following thing always happens
  - DF/ない F+と
  - 春になると花が咲き始めます。
  - 食べないと元気がでませんよ。

**Work after Class**

- Kanji: 的 洋服 授業 講義
- Week 21 Verbs
- Write about your college life

**Learning objectives**

- to be able to identify transitive / intransitive verbs
- to revise て F ＋しまう
- to be able to make *whenever* conditional sentences by using DF/ない F+と

### Lesson 6: John's Part-time job 3

Textbook chapter: (第 18 課 – III)

- Talking about things you do at the same time
- Expressing your regrets

**Grammar Structures & Expressions**

- Expressing gratitude

**Work after Class**

- Write about your friend's college life

**Learning objectives**

- to be able to tell two things you do at the same time
- to be able to express your regrets by using ～ばよかったです。
- to revise the grammar contents of the course
- to revise and consolidate the grammar contents of the course
- to practise for the L7 assessment

### Lesson 8: Meeting the Boss 1

Textbook chapter: (第 19 課 – I)

**Language Functions**

- Describing someone's actions with respect
- Giving respectful advice

**Grammar Structures & Expressions**

- Revision (L1 ~L7)
- Introduction of **Honorific Verbs**
  - いる/ 行く/ 来る → いらっしゃる
  - 食べる/ 飲む → めしあがる
  - 言う → おっしゃる
  - もらう → いただく
  - くれる → くださる
  - する → なさる / される
- Making a request
  - 切符をお取りください。
  - 説明をお読みください。
- Re-cap
- Making a request (L16)
  - てF+いただけませんでしょうか。
  - いただけませんか。
- Culture – Gift-giving in Japan -敬語-

**Work after Class**

- Kanji: 不 様 卒業 研究/ 修
- Week 25 Verbs
- Read お礼の手紙 「小野様」P319

**Learning objectives**

- to practise using 敬語
- to be able to change verbs into honorific verbs
- to be able to ask a request politely

### Lesson 10: Meeting the Boss 3

Textbook chapter: (第 19 課– III)

**Language Functions**

- Telling a thing "It is supposed to be ～" or "It should be ～"

**Grammar Structures & Expressions**

- Plain Style structure
  - PS + はずです
  - *It is supposed to be the case…*
  - 平日、大学は開くはずです。
  - 週末、図書館は開かないはずです。
  - この電車は速いはずです。
  - 野菜は高くないはずです。
  - ハロッズは、有名なはずです。
  - そのパブは静かじゃないはずです。
  - 明くんは学生の/じゃないはずです。
- Honorific form of nouns and adjectives
  - お＿ お名前, お元気, お忙しい
  - ご＿ ご住所, ご家族, ご親切

**Work after Class**

- Kanji: 質問 訪問 多い
- Week 27 Verbs
- Write お礼状

**Learning objectives**

- to practise using 敬語
- to be able to use PS + はずです
- to be able to use honorific 「お」「ご」

### Lesson 11: Mary's Shopping 1

Textbook chapter: (第 20 課– I)

**Language Functions**

- Using 敬語

**Grammar Structures & Expressions**

- Extra-modest expressions
  - いる → おります
  - 行く/ 来る → まいります
  - 食べる/ 飲む → いただきます
  - 言う → もうします
  - ある → ございます
  - です → でございます
  - もらう → いただく
  - あげる → さしあげる
- Humble expressions
  - お＋stem + する
  - *I (humbly) do…..*
  - 昨日、校長先生にお会いしました。
  - 先生から本をお借りしました。
  - 今夜お電話します。
  - 今夜お電話をさしあげます。

**Work after Class**

- Kanji: 皿 声 訪問 茶 喫茶店 心 痛
- Week 28 Verbs
- Read 落語 「猫の皿」P327

**Learning objectives**

- to practise using 敬語
- to be able to use extra-modest expressions
- to be able to use humble expressions
