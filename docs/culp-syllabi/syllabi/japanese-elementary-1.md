## Michaelmas term

### Lesson 1: Introducing Friends and Family/ one's hometown

**Language Functions**

- Describing features of people and items
- Describing your hometown /home country

**Grammar Structures & Expressions**

- Revision of Basic 2
- Verb form structures
  - Dictionary /Te/Masu Form
- Adjectives
  - i/na conjugations
  - Joining two adjectives
- What kind of ~? =どんな~ですか？
- Special adjectives
  - 持っている/ 知っている/ 住んでいる
  - やせて/ふとっている かけている
  - けっこんしている/ついている
- Ⓥ Family members (Revision)

**Work after Class**

- Kanji: 暑 寒 楽 忙
- Katakana: Na-adjectives ハンサム/スタイル リッチ/ ヘルシー デラックス etc.
- Read 「今年の夏休み」

**Learning objectives**

- to introduce your friends/ family on a business occasion
- to use a variety of adjectives
- to use a variety of adverbs
- to be able to make "progress" sentences

### Lesson 2: Last Summer Holiday 1

**Language Functions**

- Talking about past events and expressing own feelings about them

**Grammar Structures & Expressions**

- Adjectives (past)+ Conjunctions
- How was it? = どうでしたか？
- making ない Form
- Intro ない Form Structures
  1. Please do not do . = 〜ないでください。
  2. It's better not to do . = 〜ないほうがいいです。
- Plain Style +と思います。
- Because~ = 〜から/ 〜ので

**Work after Class**

- Kanji: 新 古 遠 近
- NForm Practice
- Write a short piece about your holiday

**Learning objectives**

- to explain a series of past events in chronological order
- to be able to change verbs from MF→NF(nai form)
- to be able to state an opinion with "I think ～"

### Lesson 3: Cooking and Japanese Food

**Language Functions**

- Giving instructions

**Grammar Structures & Expressions**

- Te-forms Revision
  1. do one thing followed by another = 〜て〜て
  2. get something done in preparation = てＦ＋おきます。
- Counting items
- Read a カレーライス recipe.

**Work after Class**

- Kanji: 雨 雪 晴 分 料理
- Write a recipe of your favorite food.

**Learning objectives**

- to use a variety of Te-structures confidently
- to read and write a simple instruction
- to learn about Japanese food and table manners

### Lesson 4: Preparing for a Holiday

**Language Functions**

- Giving advice
- Explaining the reason for or cause of a situation
- Indirect Speech

**Grammar Structures & Expressions**

- Introduction of Ta-forms
  1. Giving advice = たＦ＋ほうがいいです。 = ないＦ＋ほうがいいです。
- Because~ = 〜から/ 〜ので
  1. Plain Style = PS＋と言っていました。
- Revision of Counters people/objects

**Work after Class**

- Kanji: 旅行 外国 思 海外 持 知
- Read 「旅行に行く前に」

**Learning objectives**

- to use Ta-F and Nai-F Structures
- to familiarize using Plain Style Verbs
- to be able to use indirect speech sentences
- to be able to give some advice (Revision)

### Lesson 5: Having everyday conversations; Exchanging Texts/e-mail (in an informal situation)

**Language Functions**

- Talking with friends informally (using Plain Style)

**Grammar Structures & Expressions**

- What do you like and dislike? なにがすき? / なにがきらい?
- Uses Plain Style
  1. Nouns? = 学生？休み？
  2. Verbs?
     - DF?＝食べる？行く？作る？
     - た F?＝食べた？行った？作った？
  3. Adjectives? ＝〜ましょうか
     - iAje?＝楽しい？おいしい？
     - naAje?＝好き？有名？ハンサム
- Ⓥ Enrich i/na Adjectives
- Revision of Dates in the month

**Work after Class**

- Kanji: 写真 出/入口 住 休
- Write an e-mail to a Japanese friend in Plain Style

**Learning objectives**

- to have an informal conversation by using Plain Style
- to learn some informal phrases for sending e-mails / Texts

### Lesson 6: Describing People and Events using relative clauses

**Language Functions**

- Talking about actions and events in the past (using Past Tense Plain Style)
- Relative Clauses

**Grammar Structures & Expressions**

- Using TF/NF(Past)
- Ⓥ Enrich i+na Adjectives
- Revision of Counters 枚/一つ

**Work after Class**

- Kanji: 色 黒 白 赤 青 黄 緑
- Write a short piece in Plain Style

**Learning objectives**

- to be able to talk and write about past events or experiences using plain Style
- to learn how to form Relative Clauses
- to describe how people and items differ by using Relative Clauses

## Lent term

### Lesson 8: Winter Holiday Plans

**Language Functions**

- Using Comparisons/ Superlatives
- Changing Adjectives to Adverbs

**Grammar Structures & Expressions**

- Revision (L1 ~L7)
- Comparison
  - AのほうがBよりadjective です。
  - AとBとどちらのほうが・・
- Superlative
  - ～の中で＿＿が一番 adjective です。
- Adjective/Noun+の (P233)
  - 大きいの、いいの、私の＿＿です。
- DF+つもりです (revision)
- Adjective+なります。
  - i-adjective - 寒い→寒くなります
  - na-adjective – 有名な→有名になります
- Particle で (method) (P236)
- Culture- Public Transportation in Japan
- Ⓥ Types of Tickets／Places in Stations

**Work after Class**

- Kanji: 早 速 長 短 正 有名
- Read 「日本に行く前に」

**Learning objectives**

- to be able to use "Comparison"/ "Superlatives" confidently
- to be able to use Adverbs
- to be able to use Adjectives in Plain Style
- to learn about the Japanese Railway System

### Lesson 9: After the Holiday 1

**Language Functions**

- Talking about one's experience

**Grammar Structures & Expressions**

- た F Structures
  - Giving examples of activities: ～たり～たりします/しました
  - Having done (Past Experiences): たことがあります。
- Famous for its ＿＿.
  - さけで 有名です
- Particleや(giving some examples)(P256)
- だけ/しか only/just

**Work after Class**

- Kanji: 売 買 始 終 起 寝
- Write about the last Christmas Holiday

**Learning objectives**

- to use た F Structures
- to be able to ask/talk about one's experiences
- to enrich knowledge of adverbs/adverbial expressions

### Lesson 10: After the Holiday 2

**Language Functions**

- Talking about one's experience
- Conditional

**Grammar Structures & Expressions**

- MF Structures (Revision)
  - Want to do/ would like to do (incl. conjugations)
    1. ～たい/～たくない (non-past); ～たかった/～たくなかった(past)
    2. ～たがる/～たがらない (non-past); ～たがった/～たがらなかった(past)
- Plain Style Structure (Intro.)
  - 時(When / If)
- Indirect Speech (Revision)
- Revision of Counters 枚 / 回

**Work after Class**

- Kanji: 意味 温度 回 枚
- Read 「病気の日」

**Learning objectives**

- to be able to make Conditional Sentences
- to be able to use 時(When / If) in a Plain Style structure
- to be able to report someone's experience or feelings using Plain Style structures

### Lesson 11: Feeling Ill 1

**Language Functions**

- Explaining one's health condition
- Giving / Receiving some advice

**Grammar Structures & Expressions**

- Plain Style Verb + んです
- MF Structure (Revision)
  - too much/ an excess: ～すぎます
- Adjective Structure (Revision)
  - too much/ too excess: adjective stem すぎます
- た/ない F Structure (Revision)
  - It's better to do/not to do
  - たF+ほうがいいです
  - ないF+ほうがいいです
- Particle ので(giving reason) (P273)
  - PS+ので
- ない F Structure (Revision)
  - Have to do / Must do
  - ないF+ければなりません
- Ⓥ parts of the body

**Work after Class**

- Kanji: 体 目 耳 手 足 顔 歯 頭
- Write a short email to seek advice from a doctor

**Learning objectives**

- to use casual speech more confidently
- to be able to state problems with health
- to be able to explain possible causes of the problem
- to understand medical advice /instructions

### Lesson 12: After Graduation 1

**Language Functions**

- Talking about future events with predictions

**Grammar Structures & Expressions**

- Use Probability
- Plain Style ＋でしょう（だろう）
  - Will/is/are probably＿＿
- MF ＋そうです。（revision）
  - Will/is/are probably＿＿
- Plain Style そうです。
  - Apparently/ I heard that

**Work after Class**

- Kanji: 県 市 道 所 町 場所 様
- Read 「将来の夢」

**Learning objectives**

- to be able to make Conditional Sentences
- to be able to state one's predictions
- to be able to use 【Apparently/ I heard that】 in indirect speech sentences.

### Lesson 13: After Graduation 2

**Language Functions**

- Talking about future plans

**Grammar Structures & Expressions**

- Use more than one structure in a sentence
  1. I'd like to do things like ….. ～たり～たりしたいです。
  2. I intend to do things like ….. ～たり～たりするつもりです。
  3. I think that I'll do things like ….. ～たり～たりすると思います。
- States things one does/did not want to do
  - ～したくないです。/～したくなかったです。
- Adverb+なります。
  - to become adverb
  - やすくなります/有名になります

**Work after Class**

- Kanji: 昼 晩 夜 開 閉
- Write about one's plans for the future

**Learning objectives**

- to be able to talk/write about future plans
- to be able to use more than one structure in a sentence
